# Sviluppo_Web

Progetto scolastico realizzato nell'anno 2024–2025 per il cortometraggio in stop-motion *“Animati – Passo a passo nell’archeologia del cinema”*. 
Comprende la creazione dei personaggi e lo sviluppo di un sito Web in WordPress per promuovere l'iniziativa, selezionato tra i progetti delle classi quinte del corso PIT.
